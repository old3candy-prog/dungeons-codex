# Dungeons Codex PWA

這是可在 iPad Safari 使用並加入主畫面的網頁 App。

## iPad 使用方式
1. 將整個資料夾部署到可提供 HTTPS 靜態網站的服務（例如 GitHub Pages）。
2. 用 iPad Safari 開啟網站網址。
3. 點分享按鈕 →「加入主畫面」→「加入」。
4. 之後即可從主畫面圖示開啟。

## 本機預覽
直接開啟 index.html 可測試主要介面；離線快取與安裝功能需透過 HTTPS 網站伺服器。

## 目前功能
- 遊戲風格首頁、分類入口
- 圖鑑搜尋與項目詳情
- 高塔策略筆記（使用瀏覽器本機儲存）
- DLC 清單
- PWA manifest 與 service worker

目前內容是初始示範資料，非官方 App，後續可擴充完整資料與圖片。
